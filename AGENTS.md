# Landing page design skill

This project follows the landing page design skill by elayadesign.

Core rules: one offer, one audience, one primary action; approved type scale; approved spacing tokens; flat backgrounds; Phosphor icons; IntersectionObserver for reveals; tagline reveal; full interaction states; specific copy; evidence over assumptions.
