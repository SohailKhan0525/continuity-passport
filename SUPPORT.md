# Support

For usage questions and product discussions, open a GitHub issue with enough context to reproduce the problem.

For suspected security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

When reporting a scanner problem, include:

- the public repository URL
- the route or scanner step involved
- the observed result
- what you expected
- relevant browser or build information

Do not include secrets, credentials, private repository contents, or sensitive production information.
